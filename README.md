# local-host-server-using-mobile-phone-in-ESP322
The project implements a wireless LED dimmer system using an ESP32 microcontroller. 
A local host server is a web server that runs inside the ESP32. When the ESP32 is connected to a Wi-Fi network, it gets a local IP address such as:
 Turn an LED ON/OFF
Display temperature and humidity
 Open or close a door with a servo motor
 Control RGB LED brightness
 Stream video (with an ESP32-CAM)
 Control home automation devices
